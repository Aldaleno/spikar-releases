# SPIKAR — downloads

Prática de inglês a falar: Slide Talk de 7 minutos, salas de voz e vídeo e speaking clubs.

Este repositório serve **apenas para distribuir a app Android**. O código-fonte é privado.

## Descarregar

Vai a **[Releases](https://github.com/Aldaleno/spikar-releases/releases/latest)** e descarrega o ficheiro `.apk` mais recente.

Site oficial: https://spikar.netlify.app

## Instalar

1. Descarrega o APK no telemóvel Android (cerca de 152 MB; se puderes, usa wi-fi).
2. Abre o ficheiro. Se o Android pedir, permite instalar apps desta origem.
3. Abre o SPIKAR e começa a praticar.

## Verificar o ficheiro (opcional)

Cada release indica o SHA-256 do APK. No PC:

```
certutil -hashfile spikar-0.1.9.apk SHA256
```
